# Relay

A multi-platform messaging application built with React, supporting web, desktop, and mobile platforms.

## Getting Started

### Web Development
1. Run `npm install`
2. Run `npm run dev`

### Desktop App (Electron)
1. Development: `npm run electron:dev`
2. Build: `npm run electron:build`

### Mobile App (Capacitor)
1. Build and sync: `npm run mobile:build`
2. Open Android Studio: `npm run cap:android`
3. Open Xcode: `npm run cap:ios`
